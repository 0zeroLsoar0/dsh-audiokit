# 生物/动物配方（audio_design）

`audio_design` 的配方表原来偏"物体与事件"：门、玻璃、爆炸、机械、UI。这一批补的是**会动的东西**：12 个生物配方，全部由现有 38 个合成预设分层拼成，不引入任何素材文件，`同 recipe + seed + intensity` 出完全相同的字节。

一条重要约定：**这些配方没有一个是"录音级"的拟音**。它们是"在混音里能读成那个东西"的合成设计，属于游戏/动画/提示音用途。每条配方下面都写了它到底像到什么程度，以及为什么有些动物干脆没做（见最后一节）。

## 设计原则

三条，决定了这 12 个配方为什么这样搭：

1. **体型 = 音区。** 鲸、蛙的能量压在 63–250 Hz；鸟、鼠、蝙蝠压在 4–8 kHz。配方之间先靠这个分开，再靠节奏。
2. **一个配方只有一层"主体"，其余是气、体、空间。** 两个同量级的主体会互相拍频，最响的那 46 ms 会随机漂到不同的干涉峰上——听起来是"声音在晃"，测出来是质心乱跳。`wolf-howl`、`insect-swarm` 都为此把主层拉开了 9 dB 以上。
3. **叫声明事件率，不声明音色。** 四声马蹄、三下翅膀、一串蛙鸣脉冲：节奏对了才像生物，音色对了只像音效。

## 逐个配方

### `insect-swarm` 虫群 —— 3.0 s，9 层

**像什么。** 一片夏夜的飞虫/蜂群：连续的翅振嗡嗡，带 30–58 Hz 的快速颤音（AM），外面裹一层 1.8 kHz 以上的带通嘶声。这是这批里最"像"的一个——因为虫群的容错最高：没有人会去认是一只还是十只虫子，只要"密度 + 嗡嗡 + 高频沙沙"同时在，耳朵就认了。

**层构成。**
- `insect-buzz` ×3（pitch 1.15 / 0.85 / 1.35，-4 / -15 / -18 dB）：主层是 -4 dB 的那只，另外两层拉开 11–14 dB 只负责"变宽、变脏"。同量级叠三层会互相拍频，最响窗漂移。
- `texture(rain)` + `hp 1800 Hz`，-10 dB：虫翅的高频沙沙。
- `texture(room)` -26 dB：把整个群包在空气里。
- `whoosh` + `bp 2800 Hz`，-19 dB：从近到远的一次密度起伏。
- `tick` ×3（-28…-30 dB）：零星翅膀撞到麦克风的"嗒"。

**怎么调。** 想更"吵"：`insect-buzz` 主层 pitch 提到 1.35、`texture(rain)` 升到 -8 dB。想更"远"：全局 `intensity: 0.7`，并把 room 层抬到 -20 dB。想要具体节奏（蟋蟀/蝉）不要改这里，用 `audio_pattern` 拿 `tick` 铺节奏更准。

### `hoofbeats` 马蹄 —— 1.8 s，12 层

**像什么。** 一匹马小跑经过：四声"叩-叩-叩-叩"，每声是木质的硬接触 + 低频体 + 一点土/碎石。四声的间隔是 330 / 280 / 250 ms，**步幅在收**，所以听起来是"跑起来"而不是"四下一次"。这是这批里第二像的：木质撞击的频谱本来就宽，`footstep-wood` 的"跟点击 + 空腔敲击"正好是蹄声的骨架。

**层构成。** 每一拍三层：
- `footstep-wood`（weight 0.68–0.72，hardness 0.76–0.82）为接触声，每拍用 `pitchScale` 0.92/0.96/1.0/1.04 微调，避免"同一只蹄子复制四遍"；
- `thud`（weight 0.5，softness 0.3）为马蹄下面的地面体；
- `scrap`（短、粗糙、-18 dB 左右）为踢起来的土。
四拍之后不再补尾，让混响自己收。

**怎么调。** 想更"快跑"：把 4 个 offset 压成 0 / 280 / 520 / 720。想更"重"：`thud` 每拍 +3 dB、`intensity: 1`；想"雪地/沙地"：`scrap` 换成更软的、把 `footstep-wood` 降到 -6 dB。要做成群马，不要复制这一个文件叠（会相位打架），而是分别渲染不同 seed 再错开 40–90 ms。

### `wing-flap` 翅膀 —— 1.6 s，10 层

**像什么。** 一只大鸟（鸽/乌鸦）起飞：三下低频气流"扑、扑、扑"（间隔 420 / 410 ms），每下带一层羽毛摩擦的细碎高频。单独听能听出"翅膀"，但它不会告诉你是什么鸟。

**层构成。** 每一下都是 `whoosh`（speed 0.35、tone 0.22、pitch 0.7，气流）+ `thud`（weight 0.55–0.6、softness 0.6，低频推力）+ `cloth`（movement 0.7，羽毛）。三层一组，三组依次减 2 dB，最后垫 1.5 s 的 `texture(wind)` 空气。

**怎么调。** 大鸟→`whoosh` pitch 0.55、`thud` 加重；小鸟（麻雀）→`whoosh` pitch 1.3、`thud` 减半、把间隔压到 90–120 ms 更像悬停。想当"蝙蝠翅膀"在这里改是没用的：蝙蝠的扑翼是 10–20 次/秒的细密脉冲，应该用 `audio_pattern` + `thud`/`tick` 生成。

### `creature-breath` 怪物呼吸 —— 2.6 s，7 层

**像什么。** 一个大东西在你旁边呼吸：先是一段费力的吸气，然后带低吼的呼气（气流 + 胸腔），最后又吸一口。`breath-inhale` 预设本来就是为"吸气"写的（有 effort 包络），所以配方的伪影很少，可信度高；配合 `creature-growl`（pitch 0.6、lp 500 Hz）的胸腔底，它读作"生物"而不是"风"。

**层构成。** `breath-inhale`（effort 0.85）0 ms / 1.35 s 两次 + `whoosh`（tone 0.2, rise 0.55）1.25 s 做呼气 + `thud` ×2 做胸腔起伏 + `creature-growl` 2.3 s 的低吼底 + `texture(room)`。

**怎么调。** 想更"近"：把 `creature-growl` 抬到 -12 dB、混响 `size` 降到 0.35；想更"大"：`breath-inhale` 的 duration 拉到 1.6 s、`thud` weight 1.0；想"受伤/喘"：在 1.9 s 再插一个更短的吸气并把 `intensity` 降到 0.8。做循环呼吸底噪请用 `audio_pattern` 排多次，不要给这个配方 `loop: true`。

### `creature-hiss` 威胁嘶声 —— 1.8 s，6 层

**像什么。** 猫/蛇/怪物被逼到角落时的"嘶——"：2.6 kHz 以上的噪声墙，前 0.16 s 有一次气流起音，底下压着一层几乎听不见的低吼（`creature-growl` pitch 0.6、lp 600 Hz）。高频噪声本身没有物种信息，所以它读起来是"有敌意的动物"，不是某一种动物。

**层构成。** `whoosh`（pitch 1.3，起音）+ `texture(rain)` 两层（hp 2.6 kHz / 3.4 kHz，一前一后形成嘶声的"厚度"）+ `scrap`（hp 3 kHz，唾沫感）+ `creature-growl`（lp 600 Hz）做威胁底 + `thud` 做身体重量。

**怎么调。** 想更"蛇"：把低吼层删掉、`texture` 两层抬 3 dB；想更"大"：`creature-growl` 升到 -10 dB、`thud` weight 0.9；想更"近"：`whoosh` pitch 降到 0.9（起音更钝）。

### `bird-chirp` 单声鸟鸣 —— 0.9 s，6 层

**像什么。** 两三声快速、干净的亮滑音（约 4–5 kHz），后面留 0.3 s 混响。它读作"小鸟在叫"，但**任何观鸟的人都不会把它认成具体物种**：真正的鸟鸣是 FM 扫频 + 快速颤音 + 谐波结构，而这里只有 `zap` 的下滑扫频 + `chime` 的固定音高 + 一个短 `riser` 的上滑，是"鸟叫"的卡通轮廓。

**层构成。** `zap`（pitch 0.95，-2 dB，下扫滑音）×2 + `chime`（pitch 0.92、decay 0.06，短促音高点）+ `riser`（tone 0.95、0.1 s、bp 3.2 kHz，上滑的那一声）+ `tick`（起音的"嗒"）+ `texture(room)` 0.5 s。

**怎么调。** 想更"清脆"：`chime` pitch 1.0、decay 0.03；想更"远"：混响 `size` 0.45、整体 `intensity: 0.8`；想"两声一组"：把 `zap` 的 offset 从 0/125 ms 缩到 0/90 ms。要具体物种请用 `audio_sampler` 放录音。

### `bird-flock` 群鸟 —— 2.2 s，13 层

**像什么。** 清晨的一片鸟：五声不同高度的高频滑音（0–900 ms 散布）+ 两声短促音高 + 三声极轻的"嗒" + 树叶/空气的 3 kHz 以上薄底。它比 `bird-chirp` 像，因为"很多声、不规律"本来就是群鸟的特征；但同样不指认物种。

**层构成。** `zap` ×5（pitch 0.74–0.97，-3…-9 dB，散布）+ `chime` ×2（-11/-14）+ `riser`（0.09 s）+ `tick` ×3（-24…-26）+ `texture(rain)` + `hp 3 kHz`（树叶气声，-23）+ `texture(wind)`（-30）。**和 `bird-chirp` 共用同一套"鸣叫"音色，只换了事件数量和叶子底噪**——这是有意的，一个配方是"一声"，一个是"一群"。

**怎么调。** 密度：加减 `zap` 层，保持最响那层比第二响高 ≥3 dB；远近：叶子层（`texture(rain)`）从 -23 到 -18 会让群鸟更"在林子里"；加"扑翅"：在 0 ms 重叠一个 `wing-flap` 的层（`whoosh` pitch 0.85 + `cloth`），不要直接叠另一个配方文件。

### `whale-song` 鲸歌 —— 5.0 s，6 层

**像什么。** 远处水下的一段低沉长吟（基频 251 Hz），第二乐句在 1.95 s 起来，最后拖着 2 s 的海洋混响。它在**低声压、远场**时相当可信；贴耳细听会露出"这不是录音"——因为它没有真正的滑音（基频是固定的，靠第二个乐句和 pad 的慢速运动制造"在唱"的错觉）。

**层构成。** `chime`（pitch 0.05、detune -700 音分、lp 700 Hz）给基频 251 Hz 的纯净长音——这是主体；`choir-pad`（lp 900 Hz）给"身体"和慢速摆动；第二个 `chime`（detune -500）给 1.95 s 的第二乐句；`texture(hum)` + lp 320 Hz 给水下低频；`texture(room)` + 0.5/0.8 的混响给海洋。

**怎么调。** 想更低（座头鲸的感觉）：`chime` 的 `detuneCents` 从 -700 改到 -1100、`lp` 降到 500 Hz；想更"孤独"：只有一层 chime + room，把 pad 降到 -20 dB；想做"鲸群"：换 seed 渲染 2–3 个，句间错开 2–4 s，绝对不要复制同一文件叠。

### `wolf-howl` 狼嚎 —— 3.2 s，6 层

**像什么。** 远处一声狼嚎：0.85 s 的气流上滑起音，然后持续的"元音"（`choir-pad` 在 1.15 kHz 带通里），中间有低吼的粗糙颤动，1.65 s 后一声更远的回声应答。**它读作"远处的犬科/狼类呼唤"，但凑近听是"合成的长音 + 颤音"，不是真狼。**

**层构成。** `choir-pad`（pitch 0.95、movement 0.85、bp 1150 Hz、q 1.4）是主体，撑住"元音"；`creature-growl` ×3（pitch 1.7 / 1.35 / 1.55，分别 bp 950 / 1350 / 1100 Hz）做共振峰式的粗粝与颤动，最后一个是 1.65 s 的回声；`riser`（0.85 s、bp 1000 Hz）做上滑起音；`texture(wind)` 做远场空气。主体比第一层 growl 高 9 dB：同量级会让两个共振峰互相拍频，最响窗在两次演奏之间跳。

**怎么调。** 想更"近"：混响 `amount` 0.5 → 0.3、`creature-growl` 抬到 -10 dB；想更"远"：`amount` 0.65、`size` 0.9，`intensity: 0.75`；想"一群狼"：换 seed 渲染后错开 1.5–3 s 叠，并把第二条整体 `intensity: 0.7`。

### `frog-croak` 蛙鸣 —— 1.4 s，11 层

**像什么。** 一声"呱——"的低频脉冲串：`tick` 以 42 ms 间隔连打 7 下、每下都过 420 Hz 低通，形成"喉部快速开合"的咔哒串，外面包 `creature-growl`（pitch 0.55、lp 520 Hz）的喉腔共鸣和 `thud` 的低频体。**它读作"蛙类的鸣叫"，但更像"电子脉冲串进了喉腔"**：真蛙鸣的脉冲率会随温度/个体变化，且每声之间有明显的包络起伏。

**层构成。** `thud`（body）+ `creature-growl`（喉腔）+ `tick` ×7（脉冲串，-7 → -13 dB，递减出"一鼓作气"的形状）+ `scrap`（bp 520 Hz，粗糙的唾液感）+ `texture(room)`（0.5 s 小空间）。

**怎么调。** 想更"牛蛙"（更低更慢）：`tick` 的 pitch 从 0.3 降到 0.2、间隔从 42 ms 拉到 55 ms、lp 从 420 降到 320 Hz；想更"小青蛙"：pitch 0.4、间隔 30 ms、`creature-growl` 降到 -18 dB。要做"蛙塘"：换 seed 渲染 3–5 个，错开 0.4–1.2 s、音高错 10–20%，比复制更像。

### `rodent-squeak` 小鼠尖叫 —— 0.9 s，6 层

**像什么。** 两声细、尖、短的高频滑音（主导分音 6.8 kHz），几乎没低频（250 Hz 以下只占 4%）。它读作"小型哺乳类在叫"，**但偏卡通**：真小鼠的尖叫更窄、更连续，而且经常超出人耳；这里为了可听性把音区压到了 4–7 kHz。

**层构成。** `zap`（pitch 0.98、`detuneCents` +500 把滑音推到 6–7 kHz）×2 + `chime`（pitch 1.0、decay 0.04，音高点）×2 + `tick`（起音）+ `texture(room)`（0.4 s）。

**怎么调。** 更"小"：`detuneCents` 再 +300、把 `chime` 层删掉；更"惨"：第二个 `zap` 的 detune 从 +300 降到 -100（下滑变成"吱——"）；做"老鼠跑过"请配合 `scrap` 的极短颗粒而不是这个配方。

### `bat-echolocation` 回声定位 —— 1.6 s，7 层

**像什么。** 两串极短的高频"嗒嗒"（5 下，成两组，间隔 = 90 ms 和 80 ms），主导分音 7.2 kHz。**它明确不是蝙蝠本体**：真实回声定位是 20–100 kHz 的 FM 扫频，人耳根本听不到；这里做的是"人能听到的那部分"——即电影里蝙蝠出现时的经典"嗒嗒"标记音。数值上也诚实：0.9 s 内 5 个事件，宽带，没有基频。

**层构成。** `tick`（pitch 1.0、hardness 1、`detuneCents` +450…+600）×5 + 一个 0.08 s 的 `chime`（hp 4.2 kHz）做金属尾 + `texture(room)` 1.3 s 的洞穴底。

**怎么调。** 想更"电影"：把第二组往后挪到 1.0 s、加一点 `reverb size` 0.75；想更"真实"（但人耳听不见）：把 `sampleRate` 提到 96000 也没用——插件的合成最高到 20 kHz，真要超声波请走 `audio_synth_graph` 的振荡器并接受"听不见"这一事实。

## 哪些动物没做，为什么

这一节是这份文档最重要的部分。以下动物**故意没有配方**，因为纯合成（没有采样、没有共振峰模型、没有音素时序）做出来只会落进"恐怖谷"：听的人立刻知道"这是假的猫"，比没有更糟。

| 动物 | 不做的原因 |
|---|---|
| **猫叫（喵）** | 人耳对猫的"喵"有极强的模板：/miˈaʊ/ 是一个**双元音 + 滑音 + 共振峰迁移**（F1 从 ~500 Hz 滑到 ~900 Hz 再回落）的复合体，还带 0.3–0.5 s 的时长轮廓。现有 38 个预设里没有可控共振峰滑音（`zap` 的滑音是宽频下扫，`chime` 是固定音高），拼出来的只会是"电子猫"。这类声音请用 `audio_sampler` 放真实录音。 |
| **狗吠（汪）** | 狗吠是"脉冲式谐波爆发 + 快速共振峰下降"，一声 0.1–0.3 s，且狗与狗之间差异极大。合成版几乎必然变成"卡通狗"，而卡通狗在严肃场景里是最刺耳的错误。 |
| **马嘶（neigh）** | 长滑音 + 快速颤动 + 双共振峰，长度 1–2 s，是这批里最接近"能做"的，但目前只能做出"轮廓对、细节假"的版本，宁可不错。若一定要，**建议先做 `hoofbeats`，马嘶用录音**：蹄声的可信度远高于嘶鸣。 |
| **公鸡打鸣 / 鸡叫** | 多段音高轮廓（4–5 个音节的固定旋律），合成会像玩具喇叭。 |
| **具体物种的鸟鸣** | `bird-chirp` / `bird-flock` 只做"鸟叫"的泛型，不做物种指认。要"画眉/夜莺/乌鸦"，请用录音。 |
| **狮子/老虎吼叫** | 现有 `creature-growl` 可以调低、调长，但出来的是"怪物吼"，不是"狮子"——大型猫科的吼声有特定的低频共振峰和 1–2 s 的渐强结构，合成认错物种比认不出更糟。`creature-hiss` / `creature-growl` 已有配方可覆盖"猛兽威胁"的**功能**需求。 |
| **海豚 / 蝙蝠本体（超声波）** | 20–100 kHz，超出本插件 44.1/48 kHz 渲染链与人类听觉。`bat-echolocation` 只做"人耳听感"的嗒嗒标记音，不是蝙蝠的发声。 |
| **蝉 / 蟋蟀的物种节奏** | 虫群给了泛型 AM 嗡嗡；具体物种靠**节奏**（秒级的规律鸣叫），那是 `audio_pattern` 的活，不该做成固定配方。 |
| **鱼 / 昆虫以外的水下生物** | 没有可信的参照，做了也无法验证。 |

## 用法与注意事项

```js
audio_design({ recipe: 'wolf-howl', seed: 3, intensity: 0.9 })
audio_design({ recipe: 'whale-song', seed: 1, duration: 7 })   // 拉长尾巴
audio_design({ recipe: 'bird-flock', seed: 2, variant: 1 })    // 同一设计的另一版演奏
```

- **确定性**：`recipe + seed + variant + intensity` 决定字节，可以直接缓存成文件路径。
- **不要给这些配方开 `loop: true`**：它们是为"一次性事件"设计的，硬循环会在接缝上听出包络跳变。要环境底噪用 `texture` 或 `insect-swarm` 单独渲染后 `audio_convert` 淡化，或干脆用 `audio_pattern`。
- **要"一群"**：换 seed 多次渲染再在时间轴上错开（`audio_bind` 的 cues 或 `audio_mix` 的 offsets），不要复制同一个文件叠加——那会相位打架，听感是"变响"而不是"变多"。
- **要放进 5.1 / 空间**：先出干声（`intensity: 0.7`、短混响配方），再用 `audio_spatial` 摆位；直接拿带长混响的成品做空间化会糊。
- **验收**：`audio_probe` 看 `peak -1 / clipping 0 / dcOffset < 0.02`；`audio_check` 带 `question` 时可以问"这听起来像远处的狼嚎吗"，把主观判断也留痕。

## 怎么复现这份文档里的数字

```bash
node test/creatures.mjs
```

输出就是上面那张表（seed 1），并断言：每个配方渲染正常、时长与 `targetDurationMs` 一致、无削波/无 DC、峰值 -1 dBFS；同 seed 字节一致、换 seed 变；`variant` 是同一设计；`intensity` 单调；12 个配方两两在八度带指纹/事件率/波峰因数上可分；体型与音区的关系成立。`node test/design.mjs` 会把这 12 个配方和其余 26 个放在一起跑同一套契约（确定性、variant、intensity、循环、性能）。
