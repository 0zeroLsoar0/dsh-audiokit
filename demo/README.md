Current demos (rebuilt against the 0.6.0 plugin tree; run every command from the workspace root with the bundled node at `C:\Users\Administrator\.dsh\dsh-runtimes\dsh-primary-runtime\dependencies\node\bin\node.exe`):

- `demo/intro/` — 16.0 s single-file intro, **4 scenes** (silent / first sound / vocabulary / promise), instrumental only: 0.6.0 dropped the synthetic-singing tool and its voicebank, so no scene, cue or chip names it. The "vocabulary" scene's chips are the **live registry** tool names (34 today), not a copied list. Rebuild with `node demo/intro/build.mjs`, verify with `node demo/intro/verify.mjs`. Details in [intro/README.md](intro/README.md).
- `demo/showall/` — 38 s "audio archive" page that exercises every registered tool; the tool list is discovered from the plugin at build time (anything newly registered is placed by keyword and reported by the build). Rebuild with `node demo/showall/build.mjs`, verify with `node demo/showall/verify.mjs`.
- `demo/dossier/` — 20 s dossier-style page (3 scenes) whose cue table is re-measured from its own mastered audio with the `audio_cues` engine. Rebuild with `node demo/dossier/build.mjs`, verify with `node demo/dossier/verify.mjs`.

Legacy, not part of 0.6.0: `demo/build-showcase.mjs` (+ the generated `demo/showcase.html`) is the old 0.5.x single-page showcase — it imports the staging copy `dsh-audio-lab/plugin/lib`, including the `sing.js` singing engine that 0.6.0 removed, and is kept for reference only. `demo/build-sound.mjs`, `demo/render-demo.mjs` and `demo/about.html` are likewise older than the current page set.
