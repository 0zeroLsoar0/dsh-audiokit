DeepSeek Harness plugin

dsh-audio给 HTML 动画加声音 —— 让 agent 在做动画时，顺手把声音也做出来。

浏览器里的动画默认是静音的。这个插件把音频变成可测量、可迭代的东西： 每次渲染都返回峰值、RMS、波峰因数、谱质心、起音数、循环接缝与 BS.1770 响度， 于是 agent 能像调 CSS 一样调声音 —— 改参数、看数字、再听。

01它解决什么问题

没有它

动画做完了，声音要么没有，要么是随手贴上去的：不知道响度够不够、和别的素材差多少、 循环会不会"咚"一下、cue 有没有对准画面。agent 听不见，用户每次都得自己听完再描述一遍。

有它

每个声音都是一次可复现的渲染：同一个请求永远产出同样的字节，文件名由内容哈希决定， 所以可以缓存、可以回归比对；每次返回的度量让 agent 自己判断"闷不闷、响不响、接缝干不干净"。

0217 个工具

工具一句话
audio_synth渲染单个音效。38 个预设，参数是 0..1 的感知量（weight / hardness / metallic / space / tone …），可循环
audio_pattern一条规则铺满一段时间：等距、加速、随机撒点、上升扫频 —— 一次调用几百个事件
audio_design分层设计引擎，26 个配方（金属门砸、玻璃碎、远近爆炸、魔法、UI 一套、机械循环、生物、金币、远雷…）
audio_compose作曲：8 曲风、12 调式、真和声与声部进行、段落强度曲线，返回节拍表给画面卡点
audio_tts旁白：MiniMax / 任意 OpenAI 兼容端点 / 免费免密钥的 Edge（318 音色、词级时间戳）
audio_voices音色列表（配置后是账号实时列表）
audio_sing零素材唱声：共振峰合成，给音高与拼音歌词就能唱；可选接真人声库
audio_lipsync每帧口型轨（10 种 viseme + 连续张嘴量），可导出 json / srt / css / ae
audio_beats从成品音乐测 bpm、起音、节拍网格、重拍推测
audio_bind生成 cue 表与页面播放器（音频时钟预调度、手势解锁、可见性暂停、单文件内联）
audio_mix多轨合一，逐条增益与时间偏移
audio_convert裁剪 / 增益 / 淡入淡出 / 反转 / 拼接 / 批量归一 / 转码（8·16·24·32 位、单双声道、高保真重采样）
audio_stretch变速不变调、移调不变时长、精确贴合目标时长
audio_loudnessBS.1770 LUFS、真峰值、响度范围，按目标响度写校正副本
audio_probe单文件度量：峰值、RMS、波峰因数、质心、起音、循环接缝、直流
audio_check交付前质量闸：削波、近静音、迟到的攻击、cue 时间轴、叠加峰值（可选语义提问）
audio_regress快照 + 容差比对，证明改动没把别的指标带歪

03三个别人不容易替代的点

零依赖、零密钥可用

合成、设计、作曲、唱声、口型/节拍、后期、检查都不需要联网或密钥；旁白还能选免费的 Edge。装进 profile 不需要任何 npm 安装。

确定性可回归

同一请求 → 同样字节；文件名由内容哈希决定。改一个参数，audio_regress 能精确告诉你哪一行指标坏了。

可测量，不需要耳朵

响度对齐 ffmpeg（偏差 0.05 LU）、真峰值 4× 过采样、循环接缝三级度量。agent 不听也能收敛。

04快速开始

// 一个撞击，落地那一刻用
audio_synth({ preset: 'impact', params: { weight: 0.9, hardness: 0.7 }, duration: 0.6 })

// 一个"东西"，一次调用出成品
audio_design({ recipe: 'door-slam-metal' })

// 16 小节 lofi 配乐（返回 beatMap 给画面卡点）
audio_compose({ genre: 'lofi', bars: 16, key: 'F', mode: 'dorian' })

// 旁白（免费供应商）+ 字幕
audio_tts({ text: '第一句。第二句。', srt: true })

// 唱两句，再出口型轨
audio_sing({ melody: 'C4:1 E4:1 G4:2 E4:1 D4:2', lyric: 'wo ai ni' })
audio_lipsync({ path: 'assets/audio/sing.wav', fps: 24, format: 'css' })

// 接进页面：cue 表 + 播放器（可内联成单文件）
audio_bind({ cues: [{ name: 'slam', at: 0.82, path: 'assets/audio/door-slam-metal.wav' }], out: 'assets/cues' })

// 交付前把关
audio_check({ paths: ['assets/audio/slam.wav'], cues: [{ at: 0.82, src: 'assets/audio/slam.wav' }] })
audio_loudness({ path: 'assets/audio/mix.wav', targetLufs: -14 })

05同步契约（决定成片是"配过声"还是"贴上去的"）

规则为什么
一个时钟：用 AudioContext.currentTime 驱动画面一边 performance.now() 一边 audio.currentTime 一定会漂移
打击音对齐峰值，不是对齐起点wav 的第一个采样是瞬态开始，画面切点在峰值上，所以 cue 一般提前 30–50 ms
先解码再起时钟decodeAudioData 没 await 完就启动，开头会被吞掉
预调度，不用 setTimeout 当计时器source.start(t0 + at) 排在音频时钟上，误差可以做到 0 采样

这四条 audio_bind 生成的播放器已经做好了：它暴露 window.dshAudio 给动画驱动时间， 并处理了手势解锁、可见性暂停、循环防重入。

07安装与设置

# 在 DSH 里
plugin_manager  action: install_bundle   target: <插件目录>/dsh-audio

# 或命令行
dsh plugin --profile <profile> add "file:<插件目录>/dsh-audio"
# 再把 "@local/dsh-audio" 加进 profile 的 dsh.profile.bundles

装好后在 设置 → 声音 里配供应商；不配也能用。音色、测试连接、实验性的模型自检都在那一页。
