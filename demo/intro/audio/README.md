# demo/intro/audio — soundtrack for the 16 s plugin intro

Everything in this directory is rendered by the `dsh-audio-lab` engines the intro itself introduces (`compose.js` → `bed.wav`, `audio.js` → `impact.wav` + `ticks.wav`, `sing.js` → `voice.wav`, `design.js` → `end.wav`), imported straight from `plugin/lib/` as ESM and pinned to 22050 Hz mono / 16-bit PCM. `render.mjs` is the single code path that produces the five files plus `manifest.json` (cue times measured from the animation start: bed 0.0 loop, impact 2.5, ticks 6.0, voice 10.0, end 13.5 — matching `../spec.json`); fixed genres, seeds and peak targets keep it deterministic, so two consecutive runs are byte-identical (last verified: all `.wav` files and `manifest.json` hash-equal across runs). Bed is 8 cinematic bars at 120 BPM normalised to −6 dBFS and trimmed to exactly 16.000 s, so it sits under the hits without masking them; the other cues are −1/−8/−4/−3 dBFS respectively and every file decodes clean with zero clipped samples. Total audio weight is 1068 KiB, inside the ~1.2 MB budget and the spec's 900 KB single-file target once converted to base64 is the integrator's next step. Verify with `node verify.mjs` (decodes with the plugin's own `wav.js` and prints duration, peak and clipping per cue); re-render with `node render.mjs`.
